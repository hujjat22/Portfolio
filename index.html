About Me

I turn everyday frustrations into useful projects: a travel guide that helps visitors avoid overpaying, a practice space for students who freeze before a viva, a daily message for a hard day. I start with the problem, then learn whatever the build demands.

The person

Hujjat Bin Maswood

I’m a Computer Science and Engineering undergraduate at International Islamic University Chittagong, from Cox’s Bazar, Bangladesh. What drives me is building things that solve real-life problems.

First projects

Learning to think in C

I started with C and C++. My first-semester project, Traffic Dodge, is a console car-dodging game that turned loops, arrays and logic into something I could actually play.

Building with hardware

Hardware that works alone

For an EEE course I built the Auto Car Parking Gate, a smart system that uses sensors and automation to control vehicle entry and exit without anyone standing there.

The web

HTML, CSS and JavaScript

My profile site came first, then Everyday, a daily-message site, and Cox’s Bazar Unfiltered, a travel guide with a budget planner, saved places and live weather for the sea.

Frameworks and APIs

React, Vite and real data

With Anime Index I moved to React and Vite, loading shows from the public TVMaze API, adding search, and saving favorites in the browser with localStorage.
